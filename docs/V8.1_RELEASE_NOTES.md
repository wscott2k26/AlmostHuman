# Almost Human 8.1 — Complete companion-first release

Version 8.1 finishes the product-wide visual and interaction rebuild while retaining the secure developmental engine created in earlier releases.

## Experience

The access gate, onboarding, digital birth, Home, Talk, Growing, Memories, World, Activities, and Settings now use one original illustrated companion-first system. Technical provider labels are not shown in the consumer conversation.

## Authentication

Guest access creates an authenticated Supabase anonymous user and moves into onboarding immediately. Cloud restoration continues outside the critical click path. Email registration and sign-in modals no longer close when users type. Google, Apple, and Facebook controls check Supabase provider readiness before redirecting.

## Conversation speed

Early stages use reduced history, memory, fact, interest, and skill context. They make one quality-bounded model attempt with a smaller output budget and a 5.2-second provider timeout. Older stages retain two attempts and a 7.5-second provider timeout. The browser-side pending deadline is 18 seconds, with immediate optimistic message display and visible companion reaction.

## Voice

Premium voice previews and conversation playback remain server-side through the OpenAI speech endpoint. Voice identity stays recognizable while delivery matures with developmental stage.

## Verification

Three consecutive full release gates passed: 30 JavaScript tests, 208 integrity and security checks, Edge TypeScript, production build, and browser-delivery smoke test per run.

## Not included

Paid billing, signed mobile binaries, store submission, custom SMTP, and production OAuth credentials remain separate owner-controlled launch gates.
