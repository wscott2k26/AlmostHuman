# Almost Human 8.3 — The Haven + Step 7 Mobile Release

## Product advance

Version 8.3 turns the earned keepsake room into **The Haven**, a living home that develops with the companion instead of acting like a decorative store.

- Life-stage room identities evolve from a first nest to a living archive.
- Mood changes lighting and atmosphere.
- Interests and activities place earned objects in the room.
- Every object can be inspected and has a history.
- The companion receives a bounded, factual Haven summary in secure cloud chat context.
- No coins, loot boxes, purchase pressure, streak punishment, or artificial sadness.

- Local data, Supabase cloud restoration, accessibility preferences, and privacy controls remain intact.

## Expo-credit protection

The repository includes two manual-only workflows:

1. `Almost Human Step 7 iOS Build`
   - Requires the exact confirmation phrase `BUILD_ONCE`.
   - Refuses a duplicate after a successful build record exists.
   - Runs the web/cloud/security gate four times.
   - Runs the mobile preflight four times.
   - Exports both platforms before calling EAS Build.
   - Creates exactly one production iOS build and does **not** auto-submit.

2. `Submit Existing Almost Human Build to TestFlight`
   - Requires a numeric App Store Connect ID and `SUBMIT_EXISTING`.
   - Submits the already-built iOS binary.
   - Does not create or spend another build.

This split is intentional because a new App Store Connect app record may need to be created after Apple registers the bundle identifier during the first build.
